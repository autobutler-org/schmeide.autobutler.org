# Security Policy

This repository is the static site for [schmeide](https://github.com/autobutler-org/schmeide). It has no backend, no
database, and no accounts. Vulnerabilities in schmeide itself belong in the
[schmeide repository](https://github.com/autobutler-org/schmeide/security/advisories/new), not here.

## Supported Versions

Only what is currently deployed at <https://schmeide.autobutler.org> is supported. The site is rebuilt and republished
from `main` on every merge, so fixes ship as soon as they land.

## Reporting a Vulnerability

For anything exploitable, such as a supply-chain compromise in a dependency, a way to inject content into the published
page, or a misconfigured Pages deployment, **file a private advisory**, not a public issue:

<https://github.com/autobutler-org/schmeide.autobutler.org/security/advisories/new>

Include what you found, how to reproduce it, and what an attacker could do with it. We will acknowledge the report and
tell you what we intend to do about it. Do not open a public issue or pull request that demonstrates the problem before
we have responded.

## Out of scope

- Missing security headers that GitHub Pages does not let us set
- Reports generated by an automated scanner with no demonstrated impact
- Anything requiring a compromised browser, extension, or machine

## Our commitments

The site collects nothing. It has no analytics, no tag manager, no session recording, no tracking pixels, and no
third-party embeds, and it loads no scripts, fonts, or stylesheets from other origins.
